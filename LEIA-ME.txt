PASSO A PASSO (Git Bash ou terminal do VS Code)
1. Clone o repositório (se já tem, entre na pasta e rode só o "git pull"):
   git clone https://github.com/Antonio-avsp/Cloud_challenge.git
   cd Cloud_challenge
   git pull

2. Configure o Git com o SEU nome e o e-mail da SUA conta do GitHub
   (senão o commit não conta como seu):
   git config user.name "Seu Nome"
   git config user.email "seu-email-do-github@exemplo.com"

3. Copie TODO o conteúdo da pasta "arquivos" deste pacote para dentro da
   pasta Cloud_challenge, mantendo as subpastas e substituindo o que já existir.
   Não copie este LEIA-ME.

4. Faça o commit e envie:
   git add -A
   git commit -m "feat: testes automatizados e checklist de evidências"
   git push

5. Confira no GitHub se o commit aparece com o seu nome e avise o próximo do grupo.
